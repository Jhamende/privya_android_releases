# Privya — versions Android

Ce dépôt distribue les APK Android de Privya et leurs notes de version.

Téléchargements : https://github.com/Jhamende/privya_android_releases/releases

Chaque version fournit son APK signé et un fichier SHA256SUMS.txt permettant de vérifier le téléchargement. Les préversions sont destinées à la validation avant diffusion générale.

Site : https://privya.be
